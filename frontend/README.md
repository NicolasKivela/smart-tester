## Type Support for `.vue` Imports in TS

TypeScript cannot handle type information for `.vue` imports by default, so we replace the `tsc` CLI with `vue-tsc` for type checking. In editors, we need [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) to make the TypeScript language service aware of `.vue` types.

Follow these steps to enable Vue (Official) to use takeover mode (regarding type support):
* Open the command palette (ctrl+shift+p in Windows)
* Type 'Extensions: Show Built-in Extensions'
* Search for 'TypeScript and JavaScript Language Features' in the extensions tab that has appeared
* Select 'Disable (workspace)' (click on the arrow to the right of the 'Disable' button)
* Open the command palette again and enter 'Developer: Reload Window'
